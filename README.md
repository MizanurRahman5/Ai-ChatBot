# Study Buddy Ai

Build a simple, modern AI chatbot web app focused on CSE and Programming.

Features:

Clean, responsive chat interface.

Users can ask questions and receive AI-generated answers.

Allow users to upload PDF study materials and use them as a knowledge source.

Use RAG to answer questions based on uploaded documents.

Show clear error messages and loading indicators.

Add chat history and a clear-chat button.

Use a secure backend for AI API calls. Never expose API keys in frontend code.

Use React, Tailwind CSS, and Supabase if needed.

Keep the design minimal, professional, and mobile-friendly.

Build a working MVP, not just a UI mockup. Explain how to configure the AI API key and test the app.
